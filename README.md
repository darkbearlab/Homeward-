# HOMEWARD（暫定代號）

**戰敗騎士的歸鄉之路。** 單一英雄動作 roguelite。

改編自 [`darkbearlab/sleeper_roguelite`](https://github.com/darkbearlab/sleeper_roguelite)（俯視戰術射擊 × 附身式小隊 × Slay-the-Spire roguelite），
沿用其 **vanilla JS + Canvas 2D、單一 `index.html`、零依賴零資產** 的架構。

## 與原版的核心差異

| 面向 | 原版 SLEEPER | HOMEWARD |
|---|---|---|
| 操作 | 附身式：切換附身多名單位 | **只操作騎士本人**（無附身） |
| 敗北 | 全員陣亡才 run 結束 | **騎士陣亡 = run 結束** |
| 戰鬥 | 純射擊 | **近接為主 + 遠程副（弓/弩/魔法）可切換** |
| 友軍 | 附身小隊 | **AI 扈從**（沿途招募、永久死亡、可下輕量指令） |
| 主題 | 間諜「沉睡者」 | 中世紀低度奇幻・敗騎歸鄉 |
| 攝影機 | 旋轉・指標鎖定 FPS 式瞄準 | **完全沿用原版，不退化** |

## 開始遊玩

用瀏覽器直接開啟 `index.html`。發佈 GitHub Pages 後於 `https://darkbearlab.github.io/Homeward-/` 遊玩。

**開機會先進「試作場選單」**（Phase 1 手感開發中），點選或按數字鍵進場：

- **近戰試作場** — 揮斬/盾格/招架/體幹/擊退。左列訓練假人（緊排測 cleave、紫色的披甲測穿甲）、右側三名會反擊（兩名徒步兵＋一名**盾兵**）。
- **射擊試作場** — 弓弩彈道/射程/穿甲/掩體。上半標靶區（假人在 300–900 距離檔）、下半對射區（弓手×2 弩手×1 會還擊，其中一名隔著低矮牆＝敵方掩體示範）。**盾也擋得住箭**（含招架）。

進場後 `Esc` 回選單換場地、`U` 直接切下一個場、`M` 回主選單。
網址直達：`?arena=melee` / `?arena=ranged`。

**核心操作**（PoE 對齊，戰役/試作場通用）：

| | |
|---|---|
| 滑鼠移動 | 轉向（FPS 式瞄準，攝影機沿用原版） |
| 左鍵 | 揮斬（前搖 → 判定 → 後搖）。**要耐力**；前搖中被打會被打斷 |
| 右鍵 | **有盾**＝按住格擋（耗耐力，舉起瞬間的短窗＝招架）／**無盾**＝點按武器招架（窗更窄，**空招會自己硬直**）／遠程＝望遠 |
| 數字鍵 `1`~`N` | **施展第 N 個自由位**（道具/習得）。畫面底部中央有 PoE 風快捷列，一眼看得到各鍵對應什麼、好了沒 |
| 滾輪 / `X` | **換武器組**（主手 set 之間切換） |
| `空白` | 預留給「綁定誓約的主動技能」（目前 no-op） |
| `Q` | **全體扈從姿態：交戰 ↔ 避戰**（交戰＝主動接近攻擊；避戰＝只跟隨不打） |
| `G`（按住） | **指令輪盤**：滑鼠左右轉動選擇 → 放開下令（跟隨 / 守住此處 / 集中攻擊 / 先行撤離） |
| `R` / `F` / `H` | 換彈 / 互動（開關門） / 騎士自走撤離（`Shift+H`＝命令扈從先撤） |
| WASD / `Shift` | 移動 / 奔跑 |

**試作場專用熱鍵**（`arenaMode`，只在手感開發用的隔離場地生效）：

| | |
|---|---|
| `Tab` | 換主手武器（劍/斧/鎚/槍/短劍/長弓/十字弓/投槍） |
| `O` / `C` | 換副手（盾） / 換身上的甲 |
| `V` | 切換示範聖物「不屈」（每場一次：致死傷害改留 1 HP） |
| `T` / `Y` | 重來（測試對象重生滿血） / 叫敵人立刻開戰 |
| `N` / `B` | 迷霧開關 / 有無 AI 扈從 |
| `Esc` / `U` / `M` | 回試作場選單 / 切到下一個場 / 回主選單 |
| `` ` `` | 數值面板——**所有數值都在這裡即時調** |

**術：同一個東西，兩種拿法**。火矢、癒手、火油罐、煙罐、聖光——這些「術」只有一份內容，
但你可以用兩種方式帶著它，差別**不在威力，在成本**：

| | 次數 | CD | 前搖 | 耐力 | 被打斷 |
|---|---|---|---|---|---|
| **卷軸**（撿到的） | 有限 | 無 | 無，按了就出 | 不吃 | **不會** |
| **習得**（學會的） | 無限 | 有 | 有 | 吃 | **會** |

所以卷軸是**救命按鈕**（被圍住、體幹快破時，它是唯一還按得出來的東西），
習得是**可持續的工具**。找到已經學會的法術的卷軸仍然有價值——那個即時性是習得給不了的。
被打斷時不進 CD 也不扣耐力，你只是白站了那半秒。

**導師**：燒掉幾張卷軸，換這個術的永久習得。各術要燒的張數不同（癒手/包紮/火矢 2 張、藥膏/聖光 3 張、聖療 4 張）。
導師藏在**休整地**節點裡（跟營地、未來的鐵匠商人一樣），**點進去才知道這個休整地是不是導師**。
陶罐、藥劑、箭袋這些實體學不會，只會以消耗品的形式出現。

火矢走的是跟弓弩同一條彈道管線，穿甲 0.9——對披甲士的擋格率只剩 8.5%，是專門的破甲手段。

**休息關配裝（PoE 風道具面板）**：**只有騎士**能配裝（扈從用兵種給的裝備、撿到的戰利品全歸騎士），
所以休息房不再一字排開全隊卡片，而是右側一整塊面板：上半是騎士當前裝備、下半是共用倉庫。
- **倉庫物拖到裝備列＝穿**、**裝備列拖回倉庫＝脫**、**雙擊倉庫物＝快速裝到第一個相容空槽**、**右鍵倉庫物＝丟棄**。
- 左側是**只讀的隊伍列**（誰在隊上、兵種、血、主武器）；搜刮/升級要指定對象時在這裡點。
盾和甲會從軍械庫、搜刮與事件掉出來。拿雙手武器的副手格會直接寫「雙手武器（不能帶盾）」，不是留白讓你猜。

**手部與自由位**：裝備結構＝**武器組 ×2**（各自主手＋副手）＋獨立的**甲/裝備**＋**自由位**（放卷軸/習得的術）。
自由位**開局 2 個、可用榮譽升級「行囊」解鎖到 4 個**（引擎支援更多），戰鬥中對應數字鍵 `1`~`N`。
雙手武器（雙手斧・長槍・長弓・十字弓）**不能帶副手 → 不能格擋**，只剩武器招架。
投槍是唯一能搭盾的投射武器。盾有三種：小圓盾（護弧窄但招架窗最寬）／圓盾（均衡）／鳶盾（護弧最寬減傷最高，但耗耐力又難招架）。

場上左列＝訓練假人（不還手，量傷害/cleave/穿甲；紫色的有甲），右側＝會反擊的劍兵（練盾格/招架）。
畫面左上是當前武器的完整參數，右上是即時命中數據，中下是騎士的**耐力**與**體幹**兩條資源。

**兩條資源**（這是戰鬥的核心語言）：
- **耐力** — 揮擊/格擋/奔跑都要錢。歸零＝揮不動；**舉盾時耐力不足擋下 → 直接破防**。
- **體幹** — 被打會掃。扣光＝**體幹破**：大硬直 + 受傷加成（處決窗）+ 大幅擊退。
  敵人頭上的琥珀色細條就是它的體幹，看得出「再幾下就破」。

**隊伍狀態卡**在畫面左側由上而下：騎士一張完整的（武器、彈藥、術的 CD），
扈從各一張精簡的——只有名字、血、體幹細條、**目前狀態**。
挨打時整張卡**紅框加震動**；動搖會標黃字，**潰逃會閃紅字**（那代表他已經不聽指令了）。
扈從卡上不放武器與彈藥：那些你既不能操作也不需要即時知道，放上去只會擠掉你自己的資訊。

**扈從與指令**：扈從是 AI，沿途招募、永久死亡。**行為刻意簡化**——用 `Q` 一鍵切全體姿態（**交戰 ↔ 避戰**）：
交戰時**主動接近並攻擊繩長內的敵人**（優先已交戰的目標，不再呆站挨第一下才動），避戰時只跟著你、不打。
指令輪盤（`G`）另給位置層：跟隨你身邊／守住指定位置／集中攻擊指定目標／先行撤離。
- **尋路走 waypoint 圖最短路徑**（比照敵人接近方式）＝不再直線卡牆。
- **彼此保持一點安全距離**＝散開站，減少友軍誤傷、也不會被斧的一次揮擊(cleave)掃走一整排。
**扈從不會自保**：低血不會自己後撤，死生由你負責（重傷時頭頂會閃警告）。
（早期版本的「磐石／先鋒／遊獵」待機性格已移除——「有人硬有人脆」的差異改掛在**兵種**上。）

**全隊靜默**：只要**還沒有人發現你們**，扈從就按兵不動——只反擊已經在打的敵人，不主動出手破壞潛行
（他們頭上會有 🤫）。但**一旦你見血或被敵人發現，全隊自動轉為交戰**，不用你再下令。
所以你可以帶隊悄悄繞過巡邏隊，或站在旁邊看兩夥敵人自己拼個你死我活——第三方互毆不會驚動你的隊伍，
只有「有人在打**你們**」才會。想指定先打誰，用「集中攻擊」指令，它永遠無視靜默。

**扈從＝敵人，同一副身體且同一套裝備**：hp／體幹／移速／半徑／**武器／盾／甲**全部由兵種決定，
一個徒步兵站在哪一邊都是 70 血、帶劍配小盾。招募時兵種與原型分開擲——會出現「弓手的身體、陷陣的打法」的人。
**扈從的裝備不能編輯**（只有你自己能換裝）：撿到什麼都能重配的話，「這次招到弓手還是槍兵」就不再是結果了。
戰利品因此全歸騎士；配裝畫面上扈從那幾張卡標著「🔒 兵種固定」。
**唯一的例外是耐力**：只有你操作的騎士要管理耐力，扈從和敵人都沒有（AI 不做資源管理，
他們的壓力由體幹和攻擊權承擔）。騎士本人維持英雄級 100／100，不吃兵種削弱。

**陣營士氣＝品質質量的拉鋸**（詳見 `MORALE.md`）：一方的士氣＝場上各單位「品質」（**吃 HP**，殘血貢獻變少＝傷害自然轉成士氣壓力）的**加總**。
畫面正上方一條拉鋸線＝**質量占比**（你的質量 ÷ 兩邊相加），往你這邊推＝你佔上風。單位不各自持有士氣，
只持有**崩潰門檻**（純兵種）：農兵一落後就崩、徒步兵中間、披甲士要被壓到很低才崩——所以線滑動會**依序**把人壓垮，
崩潰本身又給該陣營一發負震盪＝**雪崩**。條上兩側的淺色刻度就是各兵種的崩潰門檻（我方淺藍、敵方淺紅），中央白線＝當前戰局。

**為什麼孤騎不會砍一兩刀就嚇散一群人**：一群人的品質加總通常大於一個騎士（騎士＝2×徒步兵的份量），
敵群是質量領先方、**穩得住**；你得砍出**實質減員**（大約砍掉半數、隨群大小自動縮放）才會開始雪崩。
「品質加總」本來就把**人數 × 素質**一起算了——不需要任何人數修正。

**騎士錨點**：大人物在場給隊伍一份心理安穩感（一份額外質量），但**開戰後 6 秒內快速衰退到 0**——
真打起來，光靠站在那裡的威望撐不了多久。

**震盪（momentum，半透明推擠段）**：首殺、斬將、招架給一段**暫時**的正震盪；陣亡/崩潰給該陣營負震盪。都線性退掉、
**數值刻意小**＝只是質量上的微擾（震盪太大就會像脆皮一樣砍一刀就崩）。斬掉對方菁英能立刻把線推回來。

**敵方質量占比被壓到極低＝該陣營全軍潰逃、本關已勝**（追兵停召），但場景不會立刻結束——
給你一段掃蕩時間搜刮／救人／追殺，自己決定何時從撤離點離開。我方全潰則是扈從全跑、你變孤騎——不算失敗，
騎士陣亡仍是唯一硬敗北。恢復靠：**把人聚在騎士身邊**（聚攏度）、震盪自然退掉、休息關。

**孤身一人打一群的解法不是殺光，是壓垮——砍出實質減員，讓他們自己潰散。**

**盾兵**：挨了一下而體幹沒破，他就會**舉盾一秒多再放下**。不預判、不讀你，純反射。
砍在盾上只有 1/4 傷害，而且**體幹只扣一半**——你的連段推不破他的體幹，就吃不到處決窗。

有意思的是他**把正確的節奏顛倒過來**。對一般敵人你該壓著打（停手會讓對方體幹回復，
實測等待是 −8% 收益）；對盾兵你該等（等待 +25%）。同一套動作，換個敵人就從對變成錯。
（他不會招架你——招架是讀招，是你的技巧，不會白送給 AI。）

另外：**前搖中被命中＝這一刀被打斷**（斧/鎚在判定窗中有 hyperArmor 免疫）。所以搶到先手的人贏整次交鋒，
互相硬 trade 會被體幹破直接處決。1 對多 時**同時只有 2 隻敵人能進攻**，其餘在外圍繞行伺機。

**攻擊預告**：敵人出手前會放出紅色的攻擊範圍，**填滿的那一刻就是攻擊落下的那一刻**。
只對看得見的敵人顯示（背後偷襲仍然成立）。兩種形狀：
- **近接＝扇形**，由中心向外擴散
- **遠程＝長方形彈道走廊**，由射手往外填滿、**會被牆截斷**

騎士自己不畫預告，但**扈從會**——友軍誤傷開著，你要看得到別站進他們的火線。
AI 遠程因此多了一段「瞄準」（`CONFIG.enemy.aimTime`，個別武器可用 `WEAPONS[id].aimTime` 覆寫）；
**玩家手動射擊仍是即時**，不受此限。

**友軍誤傷全面開啟**：所有攻擊都會誤傷。斧的 cleave 會砍到自己的扈從，手榴彈連自己都炸。
AI 開火前會檢查射線上有沒有自己人（否則他們會互相掃射掃光），但**玩家的手動攻擊不受此限**——自己的刀自己負責。

**裝甲有兩層**。第一層是機率「整發彈開」（擋格率 = armor × (1−pierce)），
第二層是**穿過來的那一下也吃減傷**——所以砍重裝不再是「全免或全額」的擲骰，而是穩定地砍不動。
穿甲**部分**繞過第二層，所以鎚仍然明顯是對付板甲的工具，但不會把甲抹平到毫無意義：
長劍砍披甲士要 8.8 刀、雙手斧 7.7 刀、戰鎚只要 3.1 刀，長弓要 18.5 刀（箭對板甲幾乎無效）。
**繞背同時無視兩層**——甲只罩正面。

**裝甲（第一層細節）**：機率「整發彈開」非穿甲攻擊（擋格率 = armor × (1−pierce)，繞背無視）。
被彈開的那一擊**不流血、但體幹傷害 ×1.7**——刀滑開了，衝擊還在：重裝不怕刀劍，怕鈍器。
騎士自己也能穿甲（`C` 循環），代價是移速與耐力回復——穿板甲很能挨，但揮不了幾刀就喘。
對重裝敵人的實測：劍 55% 被彈開、鎚只有 4%（左上參數表有顯示當前武器的被彈開率）。

## 戰役

`index.html?campaign` 進主選單。開新局先選**出身**——四套開局配裝，選的是打法不是強弱，
每一套都有一個明確的弱點，沒有全能選項：

| 出身 | 拿到什麼 | 弱點 |
|---|---|---|
| **守備**（劍與盾） | 長劍＋圓盾、鎖子甲 | 防禦選項最全，但輸出最低 |
| **陷陣**（雙手斧） | 雙手斧、胸甲 | hyperArmor 能硬換，但**不能格擋**，只剩武器招架 |
| **遊獵**（長弓） | 長弓＋短刀、厚襖 | 遠程風箏，被貼上就只能靠走位 |
| **習術**（火矢） | 長劍＋小圓盾、**開局就會火矢** | 唯一開局帶「習得」的，但甲最薄 |

出身只決定你自己。**開局你是一個人**——敗騎孤身上路，人手要在旅途中招募（事件／救出俘虜／收編潰兵）。
所以路線圖上事件節點不少，那是你擴軍的主要管道。

**更多出身要用榮譽解鎖**：除了 base 四種，還有**長槍騎士**（長 reach 控距）、**弩騎士**（破甲遠程）、**術士騎士**（法杖魔法彈、彈藥無限）——在「升級」畫面解鎖後才進出身選單。

**誓約（Oaths）**：選完出身多一步「配誓約」——一層**可裝備的被動 build**（詳見 `OATHS.md`）。
每位騎士有一道**綁定誓約**（本質、不可卸，例如術士的「法脈」讓魔法彈貫穿一直線）；
另有**自選誓約**（無畏＝低血輸出↑、守護＝扈從更難潰、掠奪＝榮譽↑…）靠成就解鎖、出發前裝進自由槽、run 中鎖定。

選完出身會播一段**序章**：你在屍山血海中醒來、意識到己方已敗，處決一隻啃食屍體的狼，
再解決一名搜刮戰場的敵兵，然後離開——這是你這趟歸途的起點。（Esc 可跳過。）

**沒有追兵、沒有倒數**：敵人沒理由特別派人追一個落敗的騎士，所以戰鬥沒有時間壓力，
你可以慢慢清、慢慢搜、慢慢等第三方自己拼完。（機制留著，只是先關掉。）

**每一場戰鬥都是一次小規模遭遇**，不是「一張圖撒了七個敵人」。地形固定，但**遇到誰是隨機的**：

| 遭遇 | 開場 |
|---|---|
| **攔路賊・獵犬隊** | 一開場就撲上來 |
| **巡邏隊・斥候組** | 還在巡邏，可以繞過去、也可以伏擊 |
| **哨站** | 靜態守點（槍兵＋弩手＋盾兵），被發現才動 |
| **戰團・前鋒隊** | 帶菁英的硬仗，後段才會遇到 |
| **混戰** | 兩夥敵人已經在互砍，你是第三方——站旁邊等他們消耗 |

地圖只提供地形課題（荒庭的掩體島、關隘的門、雙線迴廊的長槍封路、**曠野**的無處可躲）。
王節點例外，是固定的硬仗。路線圖上還有**休整地**（⌂）、軍械庫與事件節點。
休整地點進去才知道是什麼——營地（整補）、導師，未來還有鐵匠、商人、情報販子、營地事件（帶斥候可事先探明）。
**不管走哪條路，都會在固定深度必經一次休整地。** 打完一關會有一頁**撤離結算**（撤離成功／戰果），
按空白／Enter／點擊即回路線圖——沒有原版那套繁複的分頁。

**局內成長來自三個地方**，不是升階樹：**配裝**（武器組×2＋數個自由位＋盾/甲，從軍械庫與搜刮掉出來）、
**術**（導師節點燒卷軸習得，或路上的隱士傳授）、**聖物**（掛在事件鉤子上的效果）。
原版那套「每關二選一升被動」已整個移除——那些節點是槍械時代的（發散、換彈、連射上限），
在一個近接為主的遊戲裡大半沒有意義。

**跨局成長（meta）**在主選單的「升級」畫面用**榮譽**買：解鎖新出身、開更多**自由位**（行囊，base 2 → max 4）、
多一格**誓約槽**、以及運氣等雜項。誓約本身則靠 run 內達成條件**解鎖**（詳見 `OATHS.md`），跨局保留。

原本的主選單：`index.html?campaign`
