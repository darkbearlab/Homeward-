# HOMEWARD（暫定代號）

**戰敗騎士的歸鄉之路。** 單一英雄動作 roguelite。

改編自 [`darkbearlab/sleeper_roguelite`](https://github.com/darkbearlab/sleeper_roguelite)（俯視戰術射擊 × 附身式小隊 × Slay-the-Spire roguelite），
沿用其 **vanilla JS + Canvas 2D、單一 `index.html`、零依賴零資產** 的架構。

## 與原版的核心差異

| 面向 | 原版 SLEEPER | HOMEWARD |
|---|---|---|
| 操作 | 附身式：切換附身多名單位 | **只操作騎士本人**（無附身） |
| 敗北 | 全員陣亡才 run 結束 | **騎士陣亡 = run 結束** |
| 戰鬥 | 純射擊 | **近接為主 + 遠程副（弓/弩/魔法）可切換** |
| 友軍 | 附身小隊 | **AI 扈從**（沿途招募、永久死亡、可下輕量指令） |
| 主題 | 間諜「沉睡者」 | 中世紀低度奇幻・敗騎歸鄉 |
| 攝影機 | 旋轉・指標鎖定 FPS 式瞄準 | **完全沿用原版，不退化** |

## 開始遊玩

用瀏覽器直接開啟 `index.html`。發佈 GitHub Pages 後於 `https://darkbearlab.github.io/Homeward-/` 遊玩。

**開機會先進「試作場選單」**（Phase 1 手感開發中），點選或按數字鍵進場：

- **近戰試作場** — 揮斬/盾格/招架/體幹/擊退。左列訓練假人（緊排測 cleave、紫色的披甲測穿甲）、右側三名會反擊（兩名徒步兵＋一名**盾兵**）。
- **射擊試作場** — 弓弩彈道/射程/穿甲/掩體。上半標靶區（假人在 300–900 距離檔）、下半對射區（弓手×2 弩手×1 會還擊，其中一名隔著低矮牆＝敵方掩體示範）。**盾也擋得住箭**（含招架）。

進場後 `Esc` 回選單換場地、`U` 直接切下一個場、`M` 回主選單。
網址直達：`?arena=melee` / `?arena=ranged`。

| | |

**術：同一個東西，兩種拿法**。火矢、癒手、火油罐、煙罐、聖光——這些「術」只有一份內容，
但你可以用兩種方式帶著它，差別**不在威力，在成本**：

| | 次數 | CD | 前搖 | 耐力 | 被打斷 |
|---|---|---|---|---|---|
| **卷軸**（撿到的） | 有限 | 無 | 無，按了就出 | 不吃 | **不會** |
| **習得**（學會的） | 無限 | 有 | 有 | 吃 | **會** |

所以卷軸是**救命按鈕**（被圍住、體幹快破時，它是唯一還按得出來的東西），
習得是**可持續的工具**。找到已經學會的法術的卷軸仍然有價值——那個即時性是習得給不了的。
被打斷時不進 CD 也不扣耐力，你只是白站了那半秒。

**導師節點**（路線圖上的「書」）：燒掉幾張卷軸，換這個術的永久習得。
各術要燒的張數不同（癒手/包紮/火矢 2 張、藥膏/聖光 3 張、聖療 4 張）。
節點類型在路線圖上**事先就看得見**，所以「這條路上有導師」是你分岔時的判斷依據。
陶罐、藥劑、箭袋這些實體學不會，只會以消耗品的形式出現。

火矢走的是跟弓弩同一條彈道管線，穿甲 0.9——對披甲士的擋格率只剩 8.5%，是專門的破甲手段。

**休息關配裝**：卡片就是遊戲內的四個槽位——槽 1/2 各有自己的主手與**副手（盾）**，槽 3 放卷軸、槽 4 放習得的術，
另外還有獨立的**甲**與裝備。盾和甲現在會從軍械庫、搜刮與事件掉出來（在此之前戰役裡根本拿不到）。
拿雙手武器的那一格副手會直接寫「雙手武器（不能帶盾）」，不是留白讓你猜。

**手部與四槽位**：槽 1/2 是**手部 set**（主手＋副手），槽 3/4 是自由位（卷軸／習得的術）。
雙手武器（雙手斧・長槍・長弓・十字弓）**不能帶副手 → 不能格擋**，只剩武器招架。
投槍是唯一能搭盾的投射武器。盾有三種：小圓盾（護弧窄但招架窗最寬）／圓盾（均衡）／鳶盾（護弧最寬減傷最高，但耗耐力又難招架）。

場上左列＝訓練假人（不還手，量傷害/cleave/穿甲；紫色的有甲），右側＝會反擊的劍兵（練盾格/招架）。
畫面左上是當前武器的完整參數，右上是即時命中數據，中下是騎士的**耐力**與**體幹**兩條資源。

**兩條資源**（這是戰鬥的核心語言）：
- **耐力** — 揮擊/格擋/奔跑都要錢。歸零＝揮不動；**舉盾時耐力不足擋下 → 直接破防**。
- **體幹** — 被打會掃。扣光＝**體幹破**：大硬直 + 受傷加成（處決窗）+ 大幅擊退。
  敵人頭上的琥珀色細條就是它的體幹，看得出「再幾下就破」。

**扈從與指令**（`B` 開啟）：扈從與敵人**共用同一套性格**（磐石＝固守／先鋒＝陷陣／遊獵＝繞側翼），
差別在指令給的「錨點 + 繩長」——跟隨時待在你身邊、守住時釘在指定位置、集中攻擊時追殺指定目標。
性格決定的是**站多近**：先鋒壓到接觸（離敵 39px），磐石停在自己武器打得到的邊緣（55px，reach 58）。
**扈從不會自保**：低血不會自己後撤，死生完全由你的指令負責（所以他們重傷時頭頂會閃警告）。

**扈從＝敵人，同一副身體**：hp／體幹／移速／半徑全部來自同一張兵種表，
一個徒步兵站在哪一邊都是 70 血、45 體幹、移速 105。差別只在**武器與指令**。
招募時兵種與原型分開擲——會出現「體格是農兵、打法是先鋒」的人，所以招到誰真的有差。
**唯一的例外是耐力**：只有你操作的騎士要管理耐力，扈從和敵人都沒有（AI 不做資源管理，
他們的壓力由體幹和攻擊權承擔）。騎士本人維持英雄級 100／100，不吃兵種削弱。

**陣營士氣＝一條拉鋸**：畫面正上方**一條**，中間那道線就是戰局——往你這邊推＝你在挨打。
單位不各自持有士氣，只持有**崩潰門檻**，而且門檻是**「佔自己那半的百分比」**（純兵種）：
農兵 90%（線一歪就垮）、弓手 70%、徒步兵 55%、披甲士 20%（要打到最後才崩）。
所以戰局線滑動會**依序**把人壓垮，而且**崩潰本身又扣士氣＝雪崩**。條上的白色刻度就是各兵種的門檻。

**戰意 = 戰局位置 × 剩餘實力**。線說誰佔上風，剩餘實力說你還剩多少本錢——
所以「雙方都打到只剩兩成」時就算沒人佔上風，弱的一樣會先垮。

**氣勢（半透明推擠段）**：首殺、斬將、漂亮的招架會給你一段**暫時的氣勢**，
**只推戰局線、不動真正的士氣**，而且會線性退掉（虛線＝退盡後的位置）。
反過來也成立：**被伏擊時敵方一開場就有 +60 氣勢，你的先鋒和遊獵當場就崩，只有磐石站得住**。
這就是「敵人氣勢太盛，開打前就沒了戰意」——但**捱過去八秒，隊伍會自己站回來**，
氣勢從不造成永久傷害，而斬掉對方的菁英能立刻把線推回來。

**氣勢嚇不出擊潰**：全軍潰逃只看真正的士氣歸零，被氣勢壓到的人最多是「動搖」。

**敵方士氣歸零＝本關已勝**（全軍潰逃、追兵停召），但場景不會立刻結束——
給你一段掃蕩時間去搜刮、救人或追殺，自己決定何時從撤離點離開。
我方歸零則是扈從全部潰逃，你變孤騎——不算失敗，騎士陣亡仍是唯一硬敗北。

恢復靠：**把人聚在騎士身邊**（身邊的人越多回得越快）、擊殺敵人、休息關。打鬥中不會自己回神。

實測同一群敵人（6 農兵 + 1 披甲士）：**優先殺菁英 3.9 秒就讓對方潰散、只殺 5 個、剩 84 血**；
見人就砍要 8.6 秒、殺 6 個、只剩 59 血。**孤身一人打一群的解法不是殺光，是嚇散。**

**盾兵**：挨了一下而體幹沒破，他就會**舉盾一秒多再放下**。不預判、不讀你，純反射。
砍在盾上只有 1/4 傷害，而且**體幹只扣一半**——你的連段推不破他的體幹，就吃不到處決窗。
實測連砍 6 刀只打出 189 傷，沉住氣等他放下再砍是 252 傷。**盾兵懲罰的是亂按，不是站位。**
（他不會招架你——招架是讀招，是你的技巧，不會白送給 AI。）

另外：**前搖中被命中＝這一刀被打斷**（斧/鎚在判定窗中有 hyperArmor 免疫）。所以搶到先手的人贏整次交鋒，
互相硬 trade 會被體幹破直接處決。1 對多 時**同時只有 2 隻敵人能進攻**，其餘在外圍繞行伺機。

**攻擊預告**：敵人出手前會放出紅色的攻擊範圍，**填滿的那一刻就是攻擊落下的那一刻**。
只對看得見的敵人顯示（背後偷襲仍然成立）。兩種形狀：
- **近接＝扇形**，由中心向外擴散
- **遠程＝長方形彈道走廊**，由射手往外填滿、**會被牆截斷**

騎士自己不畫預告，但**扈從會**——友軍誤傷開著，你要看得到別站進他們的火線。
AI 遠程因此多了一段「瞄準」（`CONFIG.enemy.aimTime`，個別武器可用 `WEAPONS[id].aimTime` 覆寫）；
**玩家手動射擊仍是即時**，不受此限。

**友軍誤傷全面開啟**：所有攻擊都會誤傷。斧的 cleave 會砍到自己的扈從，手榴彈連自己都炸。
AI 開火前會檢查射線上有沒有自己人（否則他們會互相掃射掃光），但**玩家的手動攻擊不受此限**——自己的刀自己負責。

**裝甲**：機率「整發彈開」非穿甲攻擊（擋格率 = armor × (1−pierce)，繞背無視）。
被彈開的那一擊**不流血、但體幹傷害 ×1.7**——刀滑開了，衝擊還在：重裝不怕刀劍，怕鈍器。
騎士自己也能穿甲（`C` 循環），代價是移速與耐力回復——穿板甲很能挨，但揮不了幾刀就喘。
對重裝敵人的實測：劍 55% 被彈開、鎚只有 4%（左上參數表有顯示當前武器的被彈開率）。
